# TryOn — AI-Powered Virtual Fashion Try-On

TryOn is a virtual try-on platform that lets shoppers see how clothing looks on personalized avatars before purchasing. Our AI styling engine provides intelligent product recommendations based on color theory, seasonal matching, and individual preferences.

## What We Do

- **Virtual Try-On** — Photorealistic avatar-based clothing visualization
- **AI Styling** — Personalized outfit recommendations that improve over time
- **Affiliate Integration** — Seamless connection with retail partner product feeds across 9 European markets

## Tech Stack

Built with Next.js, TypeScript, and Tailwind CSS. Deployed on Vercel.

## Status

Currently in active development. Launch planned for 2026.
